## 🚢 Deployment

### For Production Deploy
```bash
npm run build
npm run start
```

### For Docker Deploy
The app can be containerized:
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY . .
RUN npm install
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]
```
