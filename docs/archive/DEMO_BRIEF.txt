QUICK START - 2 MINUTE DEMO
=====================================

1. OPEN THE APP
   URL: https://business-ai-assistant.vercel.app
   Expected: Welcome screen with greeting

2. OPEN COMMAND PALETTE
   Windows: Press Ctrl+K
   Mac: Press Cmd+K
   Expected: Command palette overlay appears

3. SCHEDULE A TASK
   Select: "Generate Quote"
   Expected: Task appears in Activity Feed (bottom right)

4. WATCH IT EXECUTE
   Observe: Task status changes in real-time
   Expected: pending → in_progress → completed

5. CHAT WITH AI
   Click: Chat button or press Chat icon
   Message: "Help me estimate a deck project"
   Expected: AI responds intelligently with suggestions

6. TOGGLE DARK MODE
   Find: Theme button (top right)
   Click: Toggle to dark mode
   Expected: Entire app switches to dark theme
