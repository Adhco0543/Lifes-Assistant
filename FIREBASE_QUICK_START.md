# Firebase Account Creation - Quick Start

**Copy-paste this guide and follow it exactly.**

---

## 5-Minute Firebase Setup

### ✅ Have These Ready:
- [ ] Google account (Gmail, or any Google account)
- [ ] 5 minutes
- [ ] Open this link: https://firebase.google.com

---

## Step 1: Sign In (1 minute)

1. Go to https://firebase.google.com
2. Click **Get Started** (top right)
3. Sign in with your Google account
   - If you don't have one, create one at https://accounts.google.com
4. Accept the Firebase terms

---

## Step 2: Create Project (2 minutes)

1. You're now in Firebase Console
2. Click **Create a project** (big button in center)
3. **Project name:** Type exactly this:
   ```
   business-ai-assistant
   ```
4. Click **Continue**

5. **Analytics:** You'll see "Enable Google Analytics"
   - Uncheck it (we don't need it)
   - Click **Create project**

6. Wait ~1 minute... you'll see a checkmark when done

---

## Step 3: Project Created! ✅

When you see the Firebase console with your project name at top, you're done.

Now copy this link and open in new tab:
```
VERCEL_ENV_SETUP.md
```

Continue from **Step 2b: Create Firestore Database** in that guide.

---

## If Something Goes Wrong:

**"Project creation failed"**
→ Try again, or use a different project name

**"Can't sign in"**
→ Create Google account first at https://accounts.google.com

**"Can't find Create Project button"**
→ Go to https://console.firebase.google.com/u/0/ directly

---

## Next Steps:

Once you see your Firebase project created:

1. Open `VERCEL_ENV_SETUP.md`
2. Start at **Step 2b: Create Firestore Database**
3. Follow all remaining steps
4. Done! 🎉

---

That's it! Firebase account in 5 minutes.
